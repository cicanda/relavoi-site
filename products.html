01 · Voice masking

Bidirectional proxy calling over PSTN

Both parties dial a temporary proxy. Relavoi identifies the caller and bridges to the other side. Each sees only the proxy.

  • Region-scoped number pools (Lagos today)
  • Configurable session cap and grace period, per tenant or per session, up to 24 hours
  • Nigerian mobile numbers only today, both parties in one country
  • Expired-session behaviour: dead line, redirect to support, or custom message
  • One-way modes when you only want A→B or B→A to connect

02 · Mobile SDKs

Verified calls your customers trust

SDKs for iOS, Android and Flutter add the trust layer PSTN can't: the customer can tell whether the call really came from you.

  • In-call verification UI: green when the call is genuinely yours, red when it isn't
  • iOS Live Activities for the call in progress, from a widget your app ships
  • Auth and token refresh, session calls and the event stream, handled for you
  • Android, iOS and Flutter, with the same session API on each
